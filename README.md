## 🚀 Quick Install

### Install Entire Skills Pack
Install all 31 skills from this repository into any local project:
```bash
npx skills add shashikant649sharma/my-agent-skills
```

Or install **globally** across your computer (available in every project workspace):
```bash
npx skills add shashikant649sharma/my-agent-skills -g
```

### Install a Specific Skill
```bash
# Frontend & Design
npx skills add shashikant649sharma/my-agent-skills --skill design-taste-frontend
npx skills add shashikant649sharma/my-agent-skills --skill emil-design-eng
npx skills add shashikant649sharma/my-agent-skills --skill apple-design

# Motion & Animation
npx skills add shashikant649sharma/my-agent-skills --skill animate
npx skills add shashikant649sharma/my-agent-skills --skill gpt-taste

# Anti-Overengineering
npx skills add shashikant649sharma/my-agent-skills --skill ponytail
npx skills add shashikant649sharma/my-agent-skills --skill ponytail-audit
```
