# ✂️ Ponytail (Anti-Overengineering & Simplicity)

Channels a senior developer who questions whether code needs to exist at all. Reaches for standard library, native platform features, and one line of code before fifty.

## ⚡ Installation & Usage

Install any individual skill from this category:
```bash
npx skills add shashikant649sharma/my-agent-skills --skill ponytail
npx skills add shashikant649sharma/my-agent-skills --skill ponytail-review
npx skills add shashikant649sharma/my-agent-skills --skill ponytail-audit
```

### When to invoke:
- Whenever code starts to feel bloated, over-architected, or dependency-heavy.
- Reviewing PRs to ask: "Can we delete this entire file and use a native browser/Node API instead?"
- Running whole-codebase audits to cut maintenance burden.
