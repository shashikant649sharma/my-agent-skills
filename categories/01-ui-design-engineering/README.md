## ⚡ Installation & Usage

Install any individual skill from this category:
```bash
npx skills add shashikant649sharma/my-agent-skills --skill design-taste-frontend
npx skills add shashikant649sharma/my-agent-skills --skill emil-design-eng
npx skills add shashikant649sharma/my-agent-skills --skill apple-design
```

### When to invoke:
- Designing a new product landing page or redesigning an existing dashboard.
- Seeking advice on font pairings, color palettes, card spacing, and elevation.
- Ensuring web apps don't look like generic AI bootstrap templates.
