## ⚡ Installation & Usage

Install any individual skill from this category:
```bash
npx skills add shashikant649sharma/my-agent-skills --skill animate
npx skills add shashikant649sharma/my-agent-skills --skill animate-expo
npx skills add shashikant649sharma/my-agent-skills --skill gpt-taste
```

### When to invoke:
- Adding physical motion or spring transitions to modals, drawers, or page routes.
- Auditing a website for sluggish or unnatural animations.
- Looking for the right technical name of a UI interaction (e.g. "what's the rubber-band bounce effect called?").
