## ⚡ Installation & Usage

Install any individual skill from this category:
```bash
npx skills add shashikant649sharma/my-agent-skills --skill image-to-code
npx skills add shashikant649sharma/my-agent-skills --skill imagegen-frontend-web
npx skills add shashikant649sharma/my-agent-skills --skill imagegen-frontend-mobile
```

### When to invoke:
- Generating standalone design comps for every section of a marketing page.
- Directing image models for iOS / Android app mockups with realistic frames.
- Re-creating pixel-accurate designs from images into code.
